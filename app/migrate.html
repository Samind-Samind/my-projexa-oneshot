ย้ายเอกสาร screens ไปใช้ id แยกจาก code

เครื่องมือรันครั้งเดียว (one-time) — เดิม document id ของ screens คือรหัสหน้าจอ (code) ตรงๆ ตอนนี้เปลี่ยนให้ document id เป็น Firestore auto-generated id (ฟิลด์ screens_id) แทน ส่วน code เป็นฟิลด์ label แยกที่แก้ไขได้อิสระ

คำเตือนก่อนกด
  • เป็นการแก้ไขข้อมูลจริงบน Firestore project ที่ตั้งค่าไว้
  • เอกสารเดิมจะถูกทำเครื่องหมาย soft-delete (is_deleted: true)
  • ใช้ "ตรวจสอบก่อน" เพื่อดูการเปลี่ยนแปลงโดยไม่เขียนข้อมูลจริง
  • รันครั้งนี้ครั้งเดียว หลังอัปเดตโค้ดแอป
